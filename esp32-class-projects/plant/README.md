# 스마트 화분 — 자동 급수

토양 수분을 측정해서 **흙이 마르면 자동으로 물을 주는** 화분입니다.
배선과 코드가 단순하고 결과가 눈앞에서 바로 보여서, **첫 성공 경험용으로 최고**예요.

## 무엇을 만드나

```
토양 수분 센서  ──▶  ESP32  ──▶  릴레이  ──▶  워터펌프
 (흙이 말랐나?)      (판단)      (스위치)     (물 주기)
                       │
                       └──▶ (확장) 폰으로 수분값 실시간 보기
```

## 왜 이걸 먼저?
- 센서 값을 **읽고 → 판단하고 → 장치를 켜는** 모든 IoT의 기본기를 가장 단순하게 경험
- 출석 프로젝트에서 배운 **웹서버**를 4단계에서 다시 써서 "수분 대시보드"를 만듦 (배운 게 이어짐)

## 단계 안내

| 단계 | 폴더 | 무엇을 / 확인 위치 |
|---|---|---|
| 1 | `step1_read_sensor` | 수분 센서 값 읽어 시리얼에 출력 — 시리얼 모니터 |
| 2 | `step2_judge_dry` | 값을 보고 "마름/촉촉" 판단 (임계값) — 시리얼 |
| 3 | `step3_auto_water` | 마르면 릴레이로 펌프 켜서 자동 급수 — 펌프 동작 |
| 4 | `step4_web_dashboard` | 폰으로 수분값 실시간 보기 + 수동 급수 버튼 — 폰 |

## 준비물
- ESP32 DevKit + USB 케이블
- **정전용량식(capacitive) 토양 수분 센서** ← 부식 적음, 저항식 말고 이걸로
- **릴레이 모듈** (1채널, 5V)
- **소형 워터펌프**(5V 수중펌프) + 실리콘 튜브
- **외부 5V 전원**(펌프용) — 휴대폰 충전기/건전지팩. ⚠ 펌프를 ESP32에서 직접 켜면 안 됨!
- 물컵, 화분(또는 실험용 흙)

## ⚠ 가장 중요한 안전 규칙
**워터펌프는 절대 ESP32 핀이나 USB에서 직접 전원을 받으면 안 됩니다.**
펌프는 전류를 많이 먹어서 ESP32가 Brownout으로 리셋돼요(출석 프로젝트에서 겪은 그 현상).
→ 펌프 전원은 **외부 5V**에서 받고, ESP32는 **릴레이로 스위치만** 합니다.

# 1·2차시 활동지 작성용 코드 안내

활동 기록지 1단계(awake robot Arm)·2단계(Code Dissection)를 채울 때 쓰는 코드 모음이다.

## 1차시 — 로봇팔 깨우기 (관절 매핑표 + 워밍업 게임)

| 활동지 항목 | 쓰는 코드 | 방법 |
|---|---|---|
| 관절 매핑표 · 서보를 하나씩 확인 (기초) | `01_servo_single_test.ino` | `PIN` 값을 2→3→9→8→4→5로 바꿔 업로드하며 "이 핀=이 관절" 확인 |
| 관절 매핑표 · 자동으로 하나씩 확인 | `02_servo_check_one_by_one.ino` | 업로드 후 시리얼 모니터를 보며 1~6번이 차례로 움직이는 것 관찰 |
| 워밍업 게임 (조이스틱 조작) | `04_basic_joystick_control.ino` | 조이스틱으로 로봇팔을 조작해 목표 지점 터치 |

> 매핑표의 **연결 핀**: 1번=2, 2번=3, 3번=9, 4번=8, 5번=4, 6번(그리퍼)=5

## 2차시 — 코드 해부 (코드 해석표 + 코드 탐정)

| 활동지 항목 | 쓰는 코드 | 방법 |
|---|---|---|
| 코드 해석표 (값 찾기) | `04_basic_joystick_control.ino` | 코드에서 SERVOS·PIN·ANA·INITANGLE·MIN/MAX·612/412 값을 찾아 적기 |
| 조이스틱 입력 핀·기준값 확인 | `03_joystick_check.ino` | 조이스틱 값(0~1023)과 612/412 경계에서 +/−/멈춤을 눈으로 확인 |
| 코드 탐정 실험 (바꾸고 관찰) | `04_basic_joystick_control.ino` | `delay()`·`MAX`·`PIN`을 하나씩 바꿔 업로드하고 변화 관찰 후 되돌리기 |

## 코드 해석표 정답(교사용 참고)
- 서보모터 개수 = **6** (`const int SERVOS = 6;`)
- 서보 핀 번호 = **2, 3, 9, 8, 4, 5**
- 조이스틱 입력 핀 = **A0~A5** (`ANA[0]~ANA[5]`)
- 초기 각도값 = **90** (그리퍼만 45)
- 최소/최대 각도 = **0~180** (그리퍼만 0~90)
- 조이스틱 기준값 = **612 / 412** (가운데 412~612는 멈춤)

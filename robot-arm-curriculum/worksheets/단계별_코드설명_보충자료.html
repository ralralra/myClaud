1awake robot Arm
서보를 하나씩 움직여 어느 관절인지 확인한다
💻 코드 — 01_servo_single_test.ino
#include <Servo.h> int PIN = 2; // ★ 이 숫자만 2→3→9→8→4→5 로 바꿔 업로드 Servo myservo; void setup() { myservo.attach(PIN); // PIN 번호에 서보 연결 } void loop() { for (int a=0; a<=90; a++){ myservo.write(a); delay(15); } // 0→90도 for (int a=90; a>=0; a--){ myservo.write(a); delay(15); } // 90→0도 }
📖 코드 설명
  • attach(PIN) : 서보를 그 핀에 연결한다. PIN 숫자만 바꿔 업로드하면 다른 서보가 움직인다.
  • write(a) : 서보를 a도로 보낸다. for문으로 0→90→0을 반복해 왕복시킨다.
  • delay(15) : 한 칸 움직일 때마다 잠깐 멈춤 → 숫자를 키우면 더 천천히.
  • 움직이는 서보를 보며 관절 매핑표(핀=관절)를 채운다.

const int SERVOS = 6; // 서보 개수 int PIN[SERVOS], MIN[SERVOS], MAX[SERVOS], INITANGLE[SERVOS], ANA[SERVOS]; void setup(){ PIN[0]=2; MIN[0]=0; MAX[0]=180; INITANGLE[0]=90; ANA[0]=0; // 1번 ... (6번까지) for(int i=0;i<SERVOS;i++){ myservo[i].attach(PIN[i]); myservo[i].write(INITANGLE[i]); } } void loop(){ value = analogRead(ANA[i]); // 조이스틱 값(0~1023) if(value>612) currentAngle++; // 한쪽 → 각도 + else if(value<412) currentAngle--; // 반대 → 각도 - }
📖 코드 설명
  • 코드는 3덩어리 — 준비(변수) · setup(설정) · loop(반복).
  • 해석표에서 찾을 값 : 서보 개수(SERVOS), 핀(PIN), 조이스틱(ANA), 시작각(INITANGLE), 최소·최대(MIN/MAX).
  • 612 / 412 : 조이스틱 값의 경계. 그 사이(가운데)는 '멈춤'.
  • 숫자를 바꿔 보며(코드 탐정) 어떤 값이 무엇을 바꾸는지 확인한다.

3Joystick Master
정밀 제어의 원리를 이해한다
💻 코드 — 04_basic_joystick_control.ino
void loop(){ delay(50); // 전체 속도(작을수록 빠름) for(int i=0;i<SERVOS;i++){ value[i] = analogRead(ANA[i]); if(value[i]>612){ if(currentAngle[i]<MAX[i]) currentAngle[i]++; // 한 번에 +1도씩만 myservo[i].write(currentAngle[i]); } else if(value[i]<412){ if(currentAngle[i]>MIN[i]) currentAngle[i]--; // -1도씩만 myservo[i].write(currentAngle[i]); } } }
📖 코드 설명
  • 각도를 한 번에 1도씩만 바꾼다 → 부드럽고 안정적인 움직임.
  • 한 번에 크게 움직이면 팔이 흔들리거나 물체를 놓친다.
  • delay(50)을 줄이면 빨라지지만 거칠어진다 → 정밀함과 속도는 트레이드오프.
  • MIN/MAX가 각도를 벗어나지 못하게 막아 안전을 지킨다.

// 만드는 법: void 이름(){ 할 일 } / 쓰는 법: 이름(); void gripperOpen(){ myservo[5].write(0); delay(400); } void gripperClose(){ myservo[5].write(90); delay(400); } void goHome(){ for(int i=0;i<SERVOS;i++) myservo[i].write(INITANGLE[i]); } // 부를 때: goHome(); gripperClose();
📖 코드 설명

  • loop() 바깥에 만들고, 어디서든 이름(); 한 줄로 부른다.
  • 복붙 대신 함수를 쓰면 코드가 짧아지고 고치기 쉽다.

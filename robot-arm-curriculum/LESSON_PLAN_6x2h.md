# 아두이노 6자유도 로봇팔 — 진로수업 상세 수업계획안 (6회 × 2시간)

> **대상** 고등학생 (기본 아두이노 경험) · **형식** 2시간 × 6회 = 총 12시간
> **성격** 진로수업 · **설계 철학** "하나씩 완성해 가는 성취형"
> — 매 회차마다 **오늘 완성한 것을 손에 쥐고** 돌아간다. 호기심·동기는
> *"오늘은 여기까지 됐다 → 다음엔 여기까지 된다"* 는 성취의 사다리에서 나온다.

관련 자료: 코드 `code/01~09`, 학습활동지 `worksheets/`, 코드 설명 `CODE_GUIDE.md`, 미션 메뉴 `README.md`.

---

## 전체 설계 한눈에 보기

| 회차 | 제목 | **오늘 완성하는 것(성취물)** | 진로 연결 | 코드 |
|---|---|---|---|---|
| 1 | 로봇팔을 내 손으로 움직인다 | 조종 가능한 로봇팔 + 관절 지도 완성 | 로봇 하드웨어 엔지니어 | 01·04 |
| 2 | 코드를 읽고 내 팔로 길들인다 | '내 팔 전용' 안정 홈 자세 세팅 | 제어·임베디드 개발자 | 04 |
| 3 | 물건을 집어 옮긴다 | 수동 Pick & Place 성공 | 물류·스마트팩토리 | 04·07 |
| 4 | 로봇과 대화하고 자세를 기록한다 | 나만의 포즈 데이터(HOME/PICK/PLACE) | 로봇 티칭·데이터 | 07 |
| 5 | 함수로 자동화한다 | 버튼 한 번에 자동 동작 완성 | 자동화 엔지니어 | 08 |
| 6 | 나만의 미션 + 데모데이 | 팀 작품 완성·시연 + 진로 발표 | 나의 진로 설계 | 08·09 |

각 회차는 **"할 수 있다 → 더 잘한다 → 스스로 만든다"** 로 상승한다.

### 하드웨어 기준값
- 그리퍼(6번 서보): 열림 **0°** / 닫힘 **90°**
- 1~5번 서보: 중심 **90°** (가동 0~180°)
- 조이스틱 SW핀 → 디지털 **7번 + GND** 버튼 추가(자동 실행용, 5회차부터)
- **외부 전원 권장**: 6축 동시 구동 시 전압 강하로 인한 떨림 방지

## 1회차 — 로봇팔을 내 손으로 움직인다

**완성 목표** 조이스틱으로 로봇팔을 마음대로 조종하고, 6개 관절이 각각 어디를 움직이는지 지도를 완성한다.
**학습목표** 로봇팔의 관절 구조와 서보모터의 역할을 이해하고, 정밀 조작의 감을 잡는다.
**사용 코드** `01_servo_single_test.ino` · `02_servo_check_one_by_one.ino` · `04_basic_joystick_control.ino` · **활동지** 1차시

| 시간 | 활동 | 진행 방식 |
|---|---|---|
| 0–15 | **오프닝·진로 훅** — "오늘 여러분은 산업용 로봇팔의 축소판을 조종합니다. 이걸 설계·정비하는 사람이 로봇 하드웨어 엔지니어예요." 완성 미리보기(교사 시연) | 강의·시연 |
| 15–35 | 구조·배선 이해(6축 서보·전원·GND) + **관절 매핑표** 조작하며 채우기 | 실습·기록 |
| 35–75 | 자유 조작 실습 + **워밍업 게임**(30초 안에 목표 지점 터치). 역할 5분씩 교대 | 모둠 실습 |
| 75–105 | **정밀 조작 챌린지** — 컵 옮기기 타임어택 또는 블록 쌓기, 팀 기록판 | 챌린지 |
| 105–120 | 완성 확인("나는 이제 로봇팔을 조종할 수 있다") + 성찰 3줄 + 진로 한마디 | 정리·성찰 |

**준비물** 로봇팔·아두이노·조이스틱, 외부 전원, 컵·블록
**평가** 관절 매핑표 완성도, 챌린지 참여도
**교사 팁** 첫 시간은 **성공 경험**이 최우선 — 코드 설명은 최소화하고 손맛부터 준다.

## 2회차 — 코드를 읽고 내 팔로 길들인다

**완성 목표** 샘플 코드 구조를 이해하고, 초기 각도를 수정해 **내 로봇팔만의 안정적인 홈 자세**를 완성한다.
**학습목표** setup/loop·핀·각도·조건문을 읽고, 값 수정이 동작에 미치는 영향을 안다.
**사용 코드** `04`(INITANGLE 수정) · **활동지** 2·4차시

| 시간 | 활동 | 진행 방식 |
|---|---|---|
| 0–10 | 복습 + 오늘 완성물 예고 — "각자 팔마다 성격이 달라요. 오늘 내 팔을 길들입니다." | 도입 |
| 10–35 | **코드 해석표** — 서보 개수·핀·각도·기준값(612/412) 찾기 | 실습·기록 |
| 35–65 | **코드 탐정 실험** — delay·MAX·PIN을 하나씩 바꿔 변화 관찰 후 되돌리기 | 탐구 실습 |
| 65–100 | **홈 포지션 만들기** — `INITANGLE` 수정 → 전원 켤 때 안정 자세로. 안정성 점검표 | 실습 |
| 100–115 | 완성 확인(재실행해도 같은 자세 복귀) + 각도값 기록 | 정리 |
| 115–120 | 진로 연결 — "값을 조정해 기계를 최적화하는 사람 = 제어 엔지니어" | 진로 |

**평가** 홈 자세 재현성, 코드 해석표
**교사 팁** "왜 이 숫자일까?"를 묻되 정답을 바로 주지 말고 **실험으로 확인**하게 한다.

## 3회차 — 물건을 집어 옮긴다

**완성 목표** 그리퍼로 여러 물체를 안정적으로 집고, **A→B 수동 Pick & Place를 성공**시킨다.
**학습목표** 그리퍼 각도(열림 0°/닫힘 90°)를 조절하고, 작업을 순서로 분해한다.
**사용 코드** `04`(또는 `07`) · **활동지** 5·7차시

| 시간 | 활동 | 진행 방식 |
|---|---|---|
| 0–10 | 복습 + 예고 — "오늘 로봇팔이 처음으로 '일'을 합니다." | 도입 |
| 10–40 | **그리퍼 장인** — 물체별 집기 실험. 마시멜로/종이컵 안 터뜨리기(섬세함 대결) | 실습·기록 |
| 40–70 | **작업 순서 설계** — 집기→들기→이동→놓기를 단계로 쪼개기 | 설계 |
| 70–105 | **택배 분류 타임어택** — A구역→B구역 수동 이동, 성공률·시간 기록 | 챌린지 |
| 105–120 | 완성 확인 + 성찰 + 진로 — "이게 물류센터·스마트팩토리의 핵심 동작" | 정리·진로 |

**준비물** 스펀지 큐브·종이컵·작은 상자·둥근 물체·마시멜로, A/B 구역 표시
**평가** 집기 실험표, Pick & Place 성공 여부
**교사 팁** "작업을 순서로 나누기"가 다음 회차 **자동화의 씨앗** — 이 개념을 꼭 짚는다.

## 4회차 — 로봇과 대화하고 자세를 기록한다

**완성 목표** 코드에 Serial을 추가해 현재 각도를 읽고, 성공한 자세를 **포즈 데이터(HOME/PICK/PLACE)로 완성**한다.
**학습목표** 시리얼 통신의 역할을 이해하고, 로봇 동작을 '숫자(데이터)'로 기록한다.
**사용 코드** `07_serial_record.ino` · **활동지** 6·8차시

| 시간 | 활동 | 진행 방식 |
|---|---|---|
| 0–10 | 복습 + 예고 — "말로 하던 걸 숫자로 남깁니다. 이게 자동화의 재료예요." | 도입 |
| 10–35 | 코드 업그레이드 — `Serial.begin`, `p` 입력으로 각도 출력 | 실습 |
| 35–65 | **자세 사진사** — 멋진 포즈를 각도값으로 캡처, 친구와 교환·재현 | 모둠 활동 |
| 65–105 | **포즈 카드 완성** — HOME·PICK_READY·PICK·PLACE_READY·PLACE 각도 기록 | 실습·기록 |
| 105–120 | 완성 확인(같은 값 → 같은 자세) + 진로 — "로봇에게 자세를 가르치는 티칭 작업" | 정리·진로 |

**평가** 포즈 데이터 완성도(재현성)
**교사 팁** 여기서 만든 각도값이 5회차 자동화에 **그대로 들어감** — "데이터가 곧 재료"임을 강조한다.

## 5회차 — 함수로 자동화한다 · **절정**

**완성 목표** 반복 동작을 함수로 만들고, **버튼 한 번에 자동 Pick & Place**를 완성한다.
**학습목표** 함수·매개변수·재사용을 이해하고, 함수 합성으로 자동화를 구현한다.
**사용 코드** `08_functions_button.ino` · **활동지** 9·10차시

| 시간 | 활동 | 진행 방식 |
|---|---|---|
| 0–10 | 복습 + 예고(완성물 시연) — "오늘 로봇이 스스로 일합니다." | 도입 |
| 10–40 | **함수 만들기** — `gripperOpen/Close` → `goHome` → `moveTo`. 왜 함수인가(복붙의 고통) | 강의·실습 |
| 40–75 | 포즈 데이터 + 함수로 `autoPickAndPlace()` 조립. 시리얼 `1`로 먼저 성공 | 실습 |
| 75–105 | **버튼(조이스틱 SW, 7번) 연결 → 원클릭 자동화 완성**. 성공률 10회 테스트·튜닝 | 실습·챌린지 |
| 105–120 | 완성 확인 + 진로 — "이게 자동화 엔지니어가 하는 일. 반복노동을 코드로 대체" | 정리·진로 |

**평가** 함수 설계표, 자동 동작 성공률
**교사 팁** 난이도 정점 — 팀 내 **역할 분담**을 명확히 하고, **시리얼로 먼저 성공**시킨 뒤 버튼으로 넘어간다.

## 6회차 — 나만의 미션 + 데모데이 & 진로

**완성 목표** 팀이 직접 설계한 미션(자동 분류·컵 피라미드·군무 등)을 완성해 **시연**하고, 활동을 진로와 연결해 발표한다.
**학습목표** 배운 것을 종합해 문제를 정의·해결하고, 자기 진로와 연결한다.
**사용 코드** `08`(필요 시 `09_dance.ino`) · **활동지** 11·12차시

| 시간 | 활동 | 진행 방식 |
|---|---|---|
| 0–15 | 미션 메뉴 제시 + 팀별 **미션 선택/설계** | 설계 |
| 15–70 | 설계·구현·반복 튜닝(성공률 올리기). 필요 시 군무 모드 | 모둠 프로젝트 |
| 70–95 | **데모데이** — 팀별 시연·상호 관람·짧은 영상 촬영 | 발표·전시 |
| 95–115 | **진로 발표** — "우리 로봇팔의 직업은? 내가 없애고 싶은 반복노동은?" | 발표 |
| 115–120 | 마무리·자기평가·생기부 근거 정리 | 정리 |

**미션 메뉴(예시)** 스피드런 · 정확도 사격 · 블록 타워 · 컵 피라미드 · 색깔/모양 분류 · 깨지기 쉬운 화물 · 도미노 · 캘리그래피 · 미니 농구 · 반 협동 컨베이어 · 사탕 자판기 · **로봇팔 군무** (자세한 내용은 `README.md` 미션 메뉴)
**평가** 미션 완성도·창의성, 진로 발표, 자기평가표·루브릭
**교사 팁** "남에게 보여준다"가 마지막 몰입을 끌어올림 — **전시·촬영을 반드시 포함**한다.

## 6회 전체를 관통하는 진로수업 장치

- **완성의 사다리** — 매회 "오늘 된 것"을 말로 확인해 성취감을 누적한다(유능감).
- **선택권** — 3·6회차에 미션 선택/설계로 자율성을 준다.
- **직업 렌즈** — 매회 끝 5분 *"오늘 활동 = 어떤 어른의 밥벌이?"* 로 목적을 심는다.
- **기록의 자산화** — 활동지를 진로활동 포트폴리오·생기부 근거로 남긴다.

## 평가 개요

- **과정 평가** 회차별 활동지(관찰·기록·정리질문)
- **수행 평가** 5회차 함수·자동화 완성도, 6회차 미션 성공률·설계·발표
- **루브릭·생기부 문장 예시** 학습활동지 마지막 장 참고

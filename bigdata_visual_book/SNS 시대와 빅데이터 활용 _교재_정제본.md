# 제1부. 데이터 리터러시: 숫자가 말을 걸다

오늘날 우리는 눈을 뜨는 순간부터 잠들기 전까지 온라인에 수많은 자취를 남긴다. 심지어 자는 동안에도 스마트 워치는 나의 몸 상태를 체크해 기록한다. 아침에 일어나면 알람을 끄고, 날씨를 확인하고, 내비게이션으로 빠른 길을 검색하거나 버스카드를 태그하고, 근처 카페에서 좋아하는 모닝커피를 결제하고, 배달 앱으로 음식을 주문하며, 플랫폼에서 영상을 시청하고, 좋아요를 누르거나 댓글과 상품평을 남기는 모든 행위가 다양한 디지털 형태로 꼼꼼히 저장되고 있다.

이러한 기록은 종이에 적힌 일기처럼 눈에 보이지는 않지만, 컴퓨터의 로그 파일처럼 차곡차곡 쌓인다. 우리가 무심코 남기는 일상의 흔적은 디지털 공간에서 하나의 데이터 조각이 되며, 이 조각들이 모여 개인의 행동 패턴과 사회의 흐름을 보여주는 중요한 단서가 되고 있다. 즉, 데이터란 특별한 전문가만 다루는 추상적인 개념이 아니라, **우리의 일상 그 자체가 숫자와 기록의 형태로 변환된 결과물**이라고 할 수 있다.

### 학습 목표

### 1.1 SNS: 데이터가 태어나는 가장 선명한 공간

IT·ICT가 일상화된 스마트 시대, SNS는 우리가 데이터를 생성하는 과정이 가장 실시간으로, 가장 선명하게 드러나는 공간이다. 스마트폰 사용자들은 깨어 있는 거의 모든 시간 동안 SNS로 자신의 감정과 행동 데이터를 쏟아낼 수 있을 뿐 아니라, 스마트폰에 내장된 GPS·가속 센서·거리 센서 등도 시시각각 사용자의 상황 정보를 양산하고 있다.

스마트폰에서 생성되는 데이터는 문자, 이미지, 영상, 클릭 스트림, 대화 기록, 소셜 미디어 플랫폼, 사물 인터넷(IoT) 데이터로 매우 다양하다. 이 외에도 기관에서 제공하는 공공데이터, 레거시 데이터베이스, 데이터를 스트리밍하는 실시간 데이터 등이 다양한 플랫폼에서 동시에 만들어진다. 플랫폼에 가입하는 과정에서 성별, 생년월일, 거주 지역 같은 기본 정보가 입력되고, 이 등록 정보는 배송·서비스 제공·계정 관리라는 명목 아래 자연스럽게 수집된다. 이용자는 단순히 서비스를 이용한다고 느끼지만, 데이터 분석가의 관점에서 보면 전혀 다른 그림이 그려진다.

| 📌 **읽을거리 — 사례 ①: 이커머스에서 일어나는 일상적 데이터 수집** |
| :---- |
| 우리가 매일 사용하는 쿠팡 같은 이커머스 플랫폼에는 어떤 데이터가 쌓이고 있을까? 단순히 이름과 전화번호뿐일까? 아니다. 무심코 누른 ‘구매’ 버튼은 생각보다 훨씬 많은 것을 기업에 알려준다. 주로 주문하는 시간대를 보면 언제 활동하고 언제 자는지 알 수 있다. 거주 환경도 드러난다. 배송 주소와 그 변경 빈도를 통해 어디에 사는지, 이사를 얼마나 자주 다니는지 알 수 있다. 무엇을 샀느냐는 더욱 결정적이다. 기저귀나 분유를 사면 아이를 키우는 집이고, 사료를 사면 반려동물과 함께 사는 집이라는 게 명확해진다. 결국 구매 단가와 브랜드 선호도가 연결되면 그 사람의 소득 수준과 소비 성향까지 추론이 가능해진다. 개별 데이터는 평범해 보이지만, **연결되는 순간 한 사람의 ‘삶의 지도’가 완성된다.** |

| 📌 **읽을거리 — 사례 ②: 데이터가 말하는 것들** |
| :---- |
| 좀 더 구체적인 상황으로 들어가 보자. <br>**“인천에 거주하는 30대 여성이 밤 10시에 로그인하여 최근 유행하는 남성 구두를 구매했다.”** <br>이 한 문장은 단순한 구매 기록처럼 보이지만, 여러 데이터가 축적되면 다음과 같은 정보 인식이 가능하다. <br>● 거주 지역과 주거 형태 (인천)<br>● 온라인 활동 시간대 (야간 활동 여부)<br>● 가족 구성이나 선물 소비 가능성 (본인이 아닌 남성 아이템 구매)<br>● 유행에 대한 민감도와 소비 성향 (최신 트렌드 반응) |

SNS에서 누르는 ‘좋아요’, 무심코 입력한 해시태그, 구매 이력, 특정 콘텐츠에 머무는 시간, 자주 가는 사이트 — 이 모두가 의미 있는 행동 데이터로 해석된다. 이용자의 의도와 무관하게 생성되는 이러한 데이터는 디지털 시대의 정보 환경에서 마치 땅속 깊이 묻혀 있던 원유처럼 빅데이터의 가치 있는 자원이 된다.

이렇게 분석된 데이터는 우리에게 ‘편리함’이라는 이름으로 돌아온다. AI는 나이와 성별에 맞게 상품을 추천하고, 경쟁사 가격을 실시간으로 모니터링해 최저가를 유지한다. 또한 우리가 다음에 무엇을 주문할지 미리 예측해 물류 센터에 물건을 배치하고, 로봇이 움직여 로켓 배송을 가능하게 만든다. 데이터가 쌓일수록 서비스는 정교해지고, 우리는 그 편리함에 더 의존하게 된다.

> 데이터는 우리 삶을 풍요롭게 만드는 강력한 도구이지만, 동시에 **나의 모든 사생활이 ‘해석’될 수 있다**는 점을 함께 생각해야 한다.

전 세계 수십억 명의 인구가 사용하는 SNS는 수십억 개의 인생을 들여다볼 수 있는 창구가 된다. 그래서 최근 빈번하게 발생하는 개인정보 유출 사고는 단순한 계정 탈취가 아닌, **한 사람의 인생 전체가 노출되는 사고**로 봐야 한다.

### 1.2 알고리즘이 만드는 개인화된 세상

수집된 방대한 데이터는 플랫폼의 알고리즘을 통해 분석되고, 우리가 보는 정보의 형태를 결정한다. 특정 유형의 영상을 자주 시청하면 추천 목록 상단에 유사한 주제가 나타나고, 음식 리뷰를 자주 보면 관련 식당 광고가 등장하는 방식이다. 플랫폼은 우리의 행동 패턴을 기반으로 ‘관심사’와 ‘선호도’를 예측하여 우리만을 위한 맞춤형 정보 환경을 구성한다.

#### 알고리즘은 어떻게 작동하는가

추천 알고리즘의 핵심은 **협업 필터링(Collaborative Filtering)**과 **콘텐츠 기반 필터링(Content-based Filtering)** 두 가지 방식이다.

- **협업 필터링** — ‘나와 비슷한 취향을 가진 사람들이 좋아한 것’을 추천하는 방식
- **콘텐츠 기반 필터링** — ‘내가 이미 좋아한 것과 유사한 특성을 가진 것’을 추천하는 방식

현재 대부분의 플랫폼은 이 두 가지를 결합한 **하이브리드 방식**을 사용한다. 유튜브의 경우 사용자가 어떤 영상을 끝까지 봤는지, 중간에 껐는지, 좋아요를 눌렀는지, 댓글을 달았는지를 모두 가중치로 계산한다. 단순히 클릭 수가 아니라 **시청 지속 시간(Watch Time)**을 핵심 지표로 삼는다. 넷플릭스는 여기서 더 나아가 사용자가 특정 장면에서 일시 정지했는지, 되감기 했는지, 어떤 시간대에 시청했는지까지 분석해 다음 콘텐츠를 결정한다. 넷플릭스가 공개한 자료에 따르면, 사용자가 플랫폼에서 보는 콘텐츠의 약 **80%가 알고리즘 추천에 의해 선택된다**.

| 📌 **읽을거리 — 사례: 같은 검색어, 다른 결과** |
| :---- |
| 동일한 검색어를 입력해도 사람마다 다른 결과가 나타난다. 예를 들어 ‘코로나 백신’을 검색했을 때, 과학 채널을 주로 시청하는 사람과 음모론 관련 영상을 자주 본 사람은 전혀 다른 정보를 보게 된다. 알고리즘은 ‘정확한 정보’가 아닌 **‘그 사람이 오래 볼 것 같은 정보’**를 우선적으로 보여주기 때문이다. <br>플랫폼 입장에서 알고리즘의 목표는 사용자가 플랫폼에 더 오래 머무르게 하는 것, 즉 **체류 시간(Engagement Time)의 극대화**이지, 정보의 정확성이나 다양성이 아니다. |

결국 우리는 추천 시스템의 편리함 속에서 스스로 정보를 선택한다고 생각하지만, 사실은 인공지능 알고리즘에 의해 안내된 소비를 하고 있는 것이다. 효율적인 일상에 동화되어 가면서, 우연한 발견의 기쁨과 낯선 관점을 만날 기회를 나도 모르게 잃어버리게 된 것은 아닐까.

### 1.3 편리함의 그림자: 필터 버블(Filter Bubble)

이러한 개인화 환경은 우리에게 큰 편리함을 주지만, 동시에 정보의 다양성을 제한하는 결과를 초래하기도 한다. 플랫폼이 이용자가 좋아할 만한 콘텐츠만 반복적으로 보여주다 보니, 특정 주제나 관점의 정보에만 갇히게 되는 현상이 발생하는데, 이를 **‘필터 버블(Filter Bubble)’**이라고 부른다. 인터넷 활동가 일라이 패리저(Eli Pariser)가 2011년 TED 강연에서 처음 대중화한 개념으로, 알고리즘이 사용자의 과거 행동을 기반으로 정보를 걸러냄으로써 그 사람만의 ‘정보 거품’ 안에 가두는 현상을 말한다.

#### 필터 버블 vs. 에코 챔버: 무엇이 다른가

필터 버블과 함께 자주 등장하는 개념이 **에코 챔버(Echo Chamber)**다. 둘 다 정보의 편향을 일으킨다는 점에서 비슷해 보이지만, 원인이 다르다.

| 구분 | 필터 버블 | 에코 챔버 |
| :--- | :--- | :--- |
| 원인 | 알고리즘이 자동으로 걸러냄 | 사람이 스스로 비슷한 생각의 집단 선택 |
| 인식 여부 | 사용자가 인식하기 어려움 | 어느 정도 의식적 선택 포함 |
| 대표 공간 | 유튜브, 인스타그램 피드, 구글 검색 | 특정 커뮤니티, 단체 채팅방, 팬덤 |

필터 버블이 더 위험한 이유는 사용자가 **인식조차 하지 못하는 상태에서** 정보가 제한되기 때문이다. 에코 챔버는 적어도 그 공간을 선택했다는 의식이 있지만, 필터 버블은 내가 원하는 정보를 보고 있다고 착각하는 상태에서 이미 편향된 정보 환경 안에 있는 것이다.

| 📌 **읽을거리 — 실제 사례: 선거와 필터 버블** |
| :---- |
| 2016년 미국 대통령 선거에서 많은 사람들이 자신이 지지하는 후보가 압도적으로 이길 것이라고 예측했다가 결과에 충격을 받았다. SNS 피드에 자신과 같은 성향의 의견만 가득했기 때문에 반대 진영의 여론을 전혀 실감하지 못했던 것이다. 이후 학계에서는 소셜 미디어 알고리즘이 정치적 양극화를 심화시킨다는 연구들이 본격적으로 등장했다. 퓨 리서치 센터(Pew Research Center)의 조사에 따르면, 미국 성인의 64%가 SNS에서 본 정보로 인해 놀라거나 혼란을 경험했다고 응답했으며, 그 원인 중 하나로 **알고리즘의 선별적 정보 노출**을 꼽았다. |

| 📌 **읽을거리 — AI와 필터 버블: 학습 데이터의 편향** |
| :---- |
| 필터 버블은 사람에게만 일어나는 현상이 아니다. 인공지능을 학습시킬 때 특정 방향으로 편향된 데이터만 반복적으로 주입되면, AI 역시 그 편향된 방향으로 판단을 내리게 된다. 인간도 학습된 환경에 따라 선입견이 생기지만 이를 인식하고 수정할 수 있다. 반면 AI는 학습 데이터 자체가 왜곡되어 있으면 스스로 그 사실을 알아차리기 어렵다. **그래서 인공지능이 도출한 결과값에 맹목적인 신뢰를 보이는 것은 쉽게 생각할 문제가 아니다.** |

#### 필터 버블에서 벗어나려면

그렇다면 우리는 어떻게 해야 할까? 몇 가지 실천 가능한 방법이 있다.

- **의도적으로 다른 관점의 콘텐츠 소비하기** — 평소와 다른 성향의 매체나 채널을 의식적으로 찾아보는 것
- **플랫폼 추천 알고리즘 초기화** — 유튜브, 넷플릭스 등 대부분의 플랫폼은 시청 기록 삭제 및 관심사 재설정 기능을 제공한다
- **검색 엔진 다양화하기** — 같은 키워드를 여러 검색 엔진에서 검색해 결과를 비교하는 습관
- **정보 출처 교차 확인하기** — 하나의 플랫폼, 하나의 채널에만 의존하지 않고 출처를 다각화하는 것

정보가 넘쳐나는 시대에 중요한 것은 얼마나 많은 정보를 접하느냐가 아니라, **얼마나 다양한 관점의 정보를 균형 있게 볼 수 있느냐**다. 데이터 리터러시의 시작은 바로 ‘내가 지금 보고 있는 정보가 어떻게 선별된 것인지’ 묻는 질문에서 비롯된다.

### 1.4 정보에서 지능으로: 데이터 리터러시의 시작

필터 버블이 보여주듯, 데이터는 우리를 편리하게도 하지만 동시에 우리가 모르는 사이 정보를 제한하기도 한다. 그렇다면 이 환경 속에서 우리에게 필요한 능력은 무엇일까? 답은 데이터를 ‘읽고 판단하는 힘’, 즉 **데이터 리터러시(Data Literacy)**다.

**데이터 리터러시란** 데이터를 단순히 읽는 것을 넘어, 데이터가 어디서 왔는지, 어떻게 수집되었는지, 무엇을 말하고 있는지, 그리고 무엇을 말하지 않는지를 파악하는 능력이다. 쉽게 말해 숫자와 그래프 앞에서 ‘이게 진짜인가?’를 물을 수 있는 비판적 사고력이다. 데이터가 넘쳐나는 시대일수록 많은 정보를 접하는 것보다 정보를 제대로 해석하는 능력이 훨씬 중요해진다.

**데이터가 지능이 된다는 것은 무슨 뜻일까?** 감이나 경험에만 의존하지 않고, 데이터와 숫자를 보고 더 나은 선택을 하는 것을 말한다. 이를 **‘데이터 기반 의사결정’**이라고 부른다. 결과적으로 SNS 시대의 정보 경험은 단순한 소비 활동이 아닌, 개인이 생성한 데이터가 다시 개인의 정보 환경을 구성하는 순환 구조다. 데이터는 곧 나 자신을 나타내게 된다.

| 📌 **읽을거리 — 사례: 같은 옷, 다른 매출** |
| :---- |
| 서울 홍대와 가로수길에 위치한 똑같은 여성 의류 전문 매장에서 똑같은 제품의 똑같은 할인폭을 가진 행사가 진행되었다. 하지만 두 곳의 매출 결과는 전혀 달랐다. 홍대 매장은 매출이 급등한 반면, 가로수길 매장은 평소와 큰 차이가 없었다. <br>왜 그럴까? 두 매장의 신용카드 구매 기록 데이터를 분석해 봤다. 홍대 매장에서는 대부분 여성의 신용카드가 사용되었지만, 가로수길 매장에서는 남성의 신용카드로 결제하는 경우가 많았다. 즉 홍대에서는 자신의 돈으로 옷을 사 입는 여성 고객이 대부분이었고, 가로수길 매장에서는 **남성이 여성에게 선물로 사 주는 경우가 많았던 것**이다. |

#### 데이터 기반 의사결정이란

예를 들어 카페 사장님이 “내 생각엔 딸기 음료가 인기 있을 것 같아”라고 추측하는 대신, 지난달 판매 데이터를 보고 실제로 가장 많이 팔린 메뉴를 확인한다면? 손해를 줄이고 매출을 높일 수 있다. 넷플릭스가 당신이 본 영화와 드라마 기록을 분석해서 “이 작품도 좋아하실 것 같아요”라고 추천하는 것도 같은 원리다.

이처럼 데이터를 잘 활용하면 시간과 돈을 아끼고, 더 좋은 결과를 만들 수 있다. 데이터는 우리가 효율적이고 더 현명한 선택을 할 수 있도록 도와주는 든든한 조력자다. 따라서 데이터가 수집되고 활용되는 환경을 이해하고, 데이터를 비판적으로 읽어내는 데이터 리터러시 역량을 갖추는 것은 디지털 사회를 살아가는 모든 사람에게 가장 필수적인 출발점이다.

### 2.1 데이터의 무게: 0과 1에서 제타바이트(ZB)까지

데이터는 형체가 없지만 분명한 ‘크기’와 ‘단위’를 가지고 있다. 컴퓨터를 구매하거나 이메일에서 파일을 첨부할 때 많이 들어 본 **비트(bit)**와 **바이트(Byte)** 같은 단위가 그것이다. 이는 컴퓨터가 계산을 시작했을 때부터 사용하던 기계어의 용량을 표현하는 단위로, 기계가 전기 신호의 ‘있다 / 없다’를 판단하는 **이진수(0 또는 1) 논리**를 바탕으로 데이터를 처리한다.

2진법 수 체계는 “현대 디지털 정보통신의 아버지”라고 불리는 미국의 수학자 **클로드 섀넌(Claude Shannon)**이 정보의 전자적 전달을 위해 정의한 원리이다. 우리가 흔히 보는 전원 버튼의 모양도 0과 1을 합쳐 만든 표시이다. 0과 1은 인간의 눈에는 숫자로 보이지만 컴퓨터 안에서는 **전기 신호가 있느냐 없느냐**로 표현된다. 먼 거리에 정보를 전달할 수 있는 인터넷, 그리고 친구에게 문자나 사진을 주고받을 수 있는 환경은 모두 클로드 섀넌 덕분이라 할 수 있다. 1937년 그가 발표한 논문 「전기와 스위칭 회로의 기호학적 분석」은 디지털 컴퓨터의 기본 개념이면서 20세기에 가장 중요하고 유명한 석사학위 논문이 되었다.

**0과 1, 두 가지 중 하나를 정하는 것이 바로 1비트(1 bit)이며, 이것이 정보(데이터)의 양을 측정하는 기준이 되었다.**

![][온오프] ![][스위치] ![][셰넌]

전기 신호를 0과 1로 처리함으로써 컴퓨터는 무한한 가능성을 갖게 되었다. 전기 신호의 유무를 판단하는 과정이 모이면 숫자 계산이 가능해지고, 사람의 언어도 판독할 수 있게 된다. 이러한 특징은 **소리·이미지·영상·텍스트** 같은 질적으로 다른 정보들을 숫자로 변환했을 때 모두 2진수 데이터로 처리할 수 있다는 논리로 확장된다. 센서의 발명으로 소리·냄새·촉감·거리·컬러·위치 등의 감지가 전기 신호로 바뀌고, 전기 신호는 10진수로, 10진수는 2진수로 처리되어 데이터화된다.

| 📌 **읽을거리 — 천공카드에서 OMR로** |
| :---- |
| 다음 이미지는 천공카드(punched card)이다. 종이에 구멍을 뚫어 0/1을 기록한 2진수 명령어로, 시험 볼 때 사용하던 OMR 카드와 비슷하다고 생각하면 이해하기 쉽다. **OMR(Optical Mark Recognition)** 기술은 사실상 천공카드 시스템의 진화된 형태이다. 천공카드는 종이에 물리적 손상(구멍)을 입혀야 하므로 수정이 불가능하고 내구성이 취약했지만, OMR은 종이를 훼손하지 않고 **빛의 반사와 흡수 신호만으로 판독**함으로써 천공카드의 단점을 보완한 사례이다. <br>![][omr]   ![][천공카드] |

데이터의 양이 폭증하면서 그 단위도 기하급수적으로 커졌고, 그에 따라 처리 속도와 저장 공간 등 데이터를 잘 보관하고 활용할 수 있는 방안이 함께 발전하기 시작했다.

- **1 비트(bit)** — 0과 1 중 하나의 신호를 저장할 수 있는 최소 단위. 8개가 모이면 8비트, 즉 1바이트가 된다.
- **1 바이트(Byte) = 8 비트** — 글자 한 개를 저장할 수 있는 용량.
- **단위의 팽창** — 킬로(KB) → 메가(MB) → 기가(GB) → 테라(TB)를 넘어, 이제는 해변의 모래알보다 많은 정보를 뜻하는 **제타바이트(ZB), 요타바이트(YB) 시대**로 진입하고 있다.

### 2.2 데이터 증가의 이유

인공지능이 처음 제기됐을 때부터 전 세계 수학자와 컴퓨터 공학자, 뇌과학자 등이 함께 연구를 했지만 쉽게 발전하지 못했던 이유 중 하나는 **데이터의 양**이었다. 인공지능이 학습해야 할 재료가 부족하면 학습 부진으로 이어지고, 인간이 놀랄 만한 수준의 성과를 낼 수 없었다. 하지만 전 세계인이 컴퓨터보다 훌륭한 스마트폰을 항상 손에 들고 다니며 데이터를 생산하는 오늘날이라면 이야기가 달라진다.

인터넷에서는 단 1분이라는 짧은 시간 동안에도 폭발적인 데이터 생성과 소통이 일어난다. 유튜브(YouTube)에는 500시간 이상의 영상이 업로드되고, 3,500만 건의 메시지 전송과 수백만 건의 구글 검색이 동시에 실행된다. 이런 빅데이터를 처리하기 위해 전 세계 전력의 약 10%가 소비되며 7,500만 대 이상의 서버가 가동된다. 동시에 CPU(직렬 처리 연산), GPU(병렬 처리 연산)도 발전하여 처리·계산 속도가 빨라지고, 데이터 저장장치도 64GB 정도의 용량을 손톱만 한 곳에 보관할 수 있을 정도로 작아졌다. 데이터는 **인터넷, 스마트폰의 대중화, 컴퓨터와 반도체의 꾸준한 업그레이드**로 증가했다고 볼 수 있다. 이제는 거의 대부분의 자료를 디지털화하여, 전 세계 의료 데이터만 해도 2025년까지 매년 약 36%씩 증가하고 있다.

#### 데이터가 폭증한 7가지 원인

1. **모바일 기기의 폭발적 증가** — 스마트폰 사용자가 전 세계적으로 수십억 명에 달하면서 데이터 생성량이 급증했다. 매일 사진과 동영상을 촬영하고, SNS에 게시물을 올리며, 인스턴트 메시지로 대화를 나눈다. 특히 고화질 사진(한 장당 수 MB)과 4K 동영상(1분당 수백 MB)의 보편화로 개인이 생성하는 데이터량은 더욱 기하급수적으로 늘었고, 실시간 스트리밍 서비스(유튜브·넷플릭스 등)의 대중화로 영상 데이터 소비와 생성도 폭증했다.

2. **사물인터넷(IoT) 기기의 확산** — 스마트홈 기기(AI 스피커·스마트 조명·온도 조절기), 자율주행차량의 센서, 공장의 스마트 설비 등 수많은 IoT 기기들이 24시간 실시간으로 데이터를 수집·전송한다. 자율주행차 한 대는 하루에 약 4 TB의 데이터를 생성하며, 이는 센서·카메라·GPS 등에서 나오는 방대한 정보다. 이를 활용해 지도 앱은 차량의 속도나 밀집도를 분석해 밀리는 구간과 빠른 길을 안내한다.(여기서 자율주행 자동차는 현재 보편화되어 있는 1~3단계 레벨을 말한다.)

3. **소셜 미디어와 온라인 활동** — 페이스북·인스타그램·X·틱톡 등의 플랫폼에서 매 초 수백만 개의 게시물·댓글·좋아요가 생성된다. 사용자들의 프로필 정보, 관계망, 행동 패턴까지 모두 데이터로 저장되며, 이는 광고 타깃팅과 추천 알고리즘에 활용된다.

4. **전자상거래와 금융 거래** — 온라인 쇼핑의 증가로 구매 이력, 장바구니 정보, 상품 리뷰, 결제 기록, 결제 시간 등이 대량으로 축적된다. 신용카드 및 모바일 결제 시스템은 모든 거래 내역을 실시간으로 기록하며, 이는 사기 탐지와 소비/생활 패턴 분석에 활용된다.

5. **기업과 공공 부문의 디지털 전환** — 기업들이 종이 문서를 디지털화하고 CRM·ERP 시스템을 도입하면서 업무 데이터가 증가했다. 공공기관도 전자정부·스마트시티 사업을 통해 교통·환경 센서·기상청·민원 데이터를 수집·분석하여 공익적 환경 조성에 활용한다. 저출산 고령화 문제도 출생·사망 신고 인구 데이터를 분석해 미래를 예측하는 데 사용되며, 우리나라의 기온 데이터는 **1904년**부터 수집되기 시작했다.

6. **과학 연구와 빅사이언스** — 유전체 분석(한 사람의 전체 유전자 정보는 약 200 GB), 우주 관측, 기후 모델링 등 과학 연구에서 수집·생성되는 데이터도 막대하다. 유럽입자물리연구소(CERN)의 대형강입자충돌기(LHC)는 연간 수십 페타바이트(PB)의 데이터를 생성하며, 기후 데이터나 우주 관측은 실시간으로 꾸준히 기록되고 있다.

7. **법적 보관 의무와 인공지능 학습 데이터** — 많은 산업 분야에서 데이터를 일정 기간(5년·10년 이상) 보관하도록 법적으로 규정한다. 금융권의 거래 기록, 의료 기록, 통신 기록 등이 삭제되지 않고 계속 축적된다. 또한 AI 모델을 학습시키기 위해서는 방대한 훈련 데이터가 필요하므로 이미지 인식·자연어 처리·음성 인식용 데이터가 수십억 건씩 수집된다.

이러한 다양한 요인들이 복합적으로 작용하면서, 우리가 생성하고 저장하는 데이터의 양은 매년 두 배 이상씩 증가하고 있으며, 이 속도는 앞으로 더욱 빨라질 것이다.

| 📌 **읽을거리 — 의료 데이터의 저장 방식** |
| :---- |
| · **전자의무기록(EMR/EHR)** — 병원에서는 환자의 진료 기록·예방접종 실시 유무·검사 결과·처방전 등을 전자의무기록 시스템에 저장한다. 과거 종이 차트에서 디지털 데이터베이스로 전환되면서 데이터 양이 급증했다. <br>· **의료 영상 데이터(PACS)** — CT·MRI·X-ray 등 의료 영상은 매우 큰 용량을 차지한다. 한 장의 고해상도 CT 스캔은 수백 MB에서 수 GB에 달하며, 이는 별도의 **의료영상저장전송시스템(PACS)**에 보관된다. <br>· **웨어러블 기기 데이터** — 스마트워치나 건강 밴드가 실시간으로 수집하는 심박수·활동량·수면 패턴 등의 데이터가 클라우드 서버에 지속적으로 축적된다. <br>· **병원 정보시스템(HIS)** — 진료 예약·수납·보험 청구 등 병원 운영 관련 모든 데이터도 통합 정보시스템에 저장된다. <br><br>의료 데이터가 매년 36%씩 성장하는 이유는 정밀 의료와 예방 의학의 확산, 웨어러블 기기의 대중화, 인공지능 진단을 위한 학습 데이터 축적, 그리고 법적으로 의료 기록을 장기간 보관해야 하는 규정 때문이다. 이러한 방대한 데이터를 분석하면 **질병 조기 발견·개인 맞춤형 치료·신약 개발** 등에 활용할 수 있어, 의료 데이터는 곧 생명을 구하는 자원이 된다. |

### 2.3 빅데이터: 3V에서 6V로

**빅데이터(Big Data)**란 수치로 명확하게 표현되는 기존의 정형화된 자료에 비정형화된 이미지·동영상·문자·언어 등이 포함된, **거대하고 다양하며 실시간**의 특징을 갖는 자료를 말한다. 최근에는 대용량 데이터 수집·저장·플랫폼·분석 기법 등을 포괄하는 용어로 변화하고 있다.

#### 정형 · 반정형 · 비정형 데이터

| 종류 | 특징 | 예시 |
| :--- | :--- | :--- |
| **정형 데이터** | 즉시 통계적 분석에 사용될 수 있는 형태로 정리·가공된 데이터 | 엑셀 테이블, 관계형 데이터베이스 |
| **반정형 데이터** | 고정된 양식은 없으나 구조나 규칙이 있는 데이터 | HTML, log, JSON, XML |
| **비정형 데이터** | 정해진 규칙이 없어 값의 의미를 쉽게 파악하기 힘든 데이터 | 사진, SNS 글, 이미지, 영상 |

전체 빅데이터 중 약 **20%를 정형 데이터**가 차지하고 나머지 **80%를 비정형**이 차지하고 있으며, IBM 보고서에 따르면 **비정형 데이터의 증가율은 정형 데이터 증가율의 약 15배**에 이른다고 한다.

| 📌 **읽을거리 — 데이터는 어디를 흐르는가: 프론트엔드와 백엔드** |
| :---- |
| 우리가 눈으로 보고 직접 사용하는 화면, 즉 앱이나 웹사이트의 인터페이스를 **프론트엔드(Front-end)**라고 한다. 반면 사용자의 요청을 처리하고 데이터를 저장하는 서버 영역을 **백엔드(Back-end)**라고 한다. 검색창에 단어를 입력하는 순간, 그 정보는 프론트엔드를 통해 백엔드로 전달되고, 서버는 이를 처리한 뒤 결과를 다시 화면으로 보내 준다. 데이터는 **사용자 → 서버 → 사용자**의 흐름을 반복하며 끊임없이 이동한다. |

| 📌 **읽을거리 — 모든 행동은 기록된다: 로그 데이터** |
| :---- |
| 데이터 흐름의 핵심이 되는 것이 바로 **로그 데이터(Log Data)**다. 로그 데이터란 사용자의 행동이 시간 순서대로 기록된 데이터로, 검색한 키워드·클릭한 페이지·머문 시간·구매 이력·접속 위치 및 기기 정보가 모두 포함된다. 우리는 단순히 인터넷을 ‘사용’하는 것이 아니라, 동시에 데이터를 끊임없이 생성하고 있는 존재다. 이렇게 쌓인 로그 데이터는 기업에게는 사용자 행동을 이해하는 핵심 자료가 되고, 정부·공공기관에서는 정책 수립과 서비스 개선에 활용된다. |

| 📌 **읽을거리 — 시크릿 모드도 로그가 남을까?** |
| :---- |
| 많은 사람이 시크릿 모드를 사용하면 모든 기록이 사라진다고 생각한다. 그러나 이는 부분적으로만 맞는 이야기다. 시크릿 모드는 **브라우저에 검색 기록을 저장하지 않고 쿠키 및 로그인 정보를 자동 삭제**하는 기능만 제공할 뿐이다. 웹사이트 서버에 기록되는 접속 로그, 인터넷 서비스 제공자(ISP)의 접속 기록, 회사나 학교 네트워크의 접속 기록은 시크릿 모드와 무관하게 그대로 남는다. <br>시크릿 모드는 ‘내 컴퓨터에 기록이 남지 않게 하는 기능’일 뿐, 인터넷 전체에서 흔적을 지우는 기능이 아니다. 이 사실은 우리가 디지털 환경에서 얼마나 많은 데이터 흔적을 남기고 있는지를 잘 보여 준다. |

#### 데이터 흐름과 보안: 왜 암호화가 필요한가

데이터가 사용자와 서버 사이를 이동하는 과정에서는 **보안 문제**가 필연적으로 발생한다. 아이디와 비밀번호, 결제 정보, 개인정보처럼 민감한 데이터가 그 경로를 통해 오가기 때문이다. 이를 보호하기 위해 **암호화(Encryption)** 기술이 사용된다. 암호화란 데이터를 알아볼 수 없는 형태로 변환하여 허가된 사람만 다시 읽을 수 있도록 만드는 기술이다. 반대로 암호를 해독하려는 시도를 **복호화(Decryption)**라고 하며, 해커들이 노리는 것이 바로 이 지점이다.

따라서 데이터가 이동하는 전 과정은 **생성 → 전송 → 암호화 → 저장 → 복호화 및 활용**의 복합적인 구조 속에서 보안 시스템과 함께 작동한다. 오늘날 데이터는 단순한 기록을 넘어 의사결정과 예측을 가능하게 하는 핵심 자원이 되었다. 추천 알고리즘, 자율주행 시스템, 의료 인공지능, 금융 예측 시스템 모두 방대한 데이터를 기반으로 작동한다. 데이터의 가치가 커질수록 이를 노리는 공격도 함께 증가한다. 결국 빅데이터 시대의 핵심 원칙은 하나다.

> **“데이터가 많아질수록, 보안의 중요성도 함께 커진다.”**

#### 가트너의 3V, 그리고 5V·6V

미국의 세계적인 정보기술 연구·자문회사 **가트너(Gartner Inc.)**는 빅데이터의 핵심 요소를 **3V**로 정의했다.

| 속성 | 의미 |
| :--- | :--- |
| **Volume (규모)** | 테라바이트 이상의 방대한 데이터 양. ICT 발전으로 디지털 정보량이 급증하면서 ZB·PB 시대로 진입 중 |
| **Velocity (속도)** | 데이터가 실시간으로 빠르게 생성·처리·이동·시각화되는 특성 |
| **Variety (다양성)** | 정형 데이터뿐 아니라 사진·오디오·비디오·SNS·로그 파일 등 비정형 데이터의 다양성 |

이후 데이터 분석의 신뢰성과 가치가 강조되면서 다음 속성이 추가로 정의되었다.

| 속성 | 의미 |
| :--- | :--- |
| **Veracity (정확성)** | 방대한 데이터일수록 부정확한 데이터도 함께 증가한다. 패턴을 설명할 만큼 신뢰할 수 있는 데이터인지의 문제 |
| **Value (가치)** | 데이터 분석을 통해 얻을 수 있는 통찰력과, 현실적인 문제 해결에 도움이 되는가의 가치 |
| **Visualization (시각화)** | 복잡한 분석 결과를 정보 사용자가 쉽게 이해할 수 있도록 가공해 보여 주는 능력 |

핵심은 여전히 3V에서 출발하지만, 데이터를 ‘얼마나 정확하게 · 가치 있게 · 알기 쉽게’ 만드는가가 곧 빅데이터의 성패를 가른다.

### 2.4 데이터 리터러시: 숫자를 읽는 사람이 세상을 읽는다

데이터가 넘쳐나는 시대라고 해서 누구나 데이터를 잘 다루는 것은 아니다. 쏟아지는 숫자와 그래프 앞에서 ‘이게 맞는 말인가?’를 물을 수 있는 사람과, 그냥 받아들이는 사람 사이의 차이는 생각보다 크다. 이 차이를 만드는 것이 바로 **데이터 리터러시(Data Literacy)**다.

데이터 리터러시란 단순히 데이터를 읽는 능력이 아니다. **데이터가 어디서 왔는지, 어떤 목적으로 수집되었는지, 무엇을 말하고 있는지, 그리고 무엇을 말하지 않는지**까지 파악하는 종합적인 판단 능력이다. 세계경제포럼(WEF)은 2020년 미래 직업 보고서에서 데이터 리터러시를 향후 10년간 가장 중요한 핵심 역량 중 하나로 꼽았다. 데이터를 생산하는 기술은 빠르게 발전하지만, 그것을 제대로 읽고 판단하는 사람은 여전히 드물기 때문이다.

![][데이터분석프로세스]

#### 데이터를 다루는 사람들은 어떻게 일하는가

데이터 리터러시를 갖춘다는 것은 전문 개발자가 되는 것이 아니다. **데이터를 분석하고 활용하는 사고의 흐름**을 이해하는 것이다. 실제 데이터 분석은 다음의 다섯 단계를 거친다.

**1단계 — 문제 정의: 무엇을 알고 싶은가**
데이터 분석은 컴퓨터가 아니라 **질문**에서 시작된다. ‘무엇을 하고자 하는가, 얻고자 하는 결과는 무엇인가’가 명확하게 정의되어야 어떤 데이터를 수집할지, 어떤 모델을 사용할지 방향이 잡힌다. 문제 정의가 흐릿하면 아무리 많은 데이터를 갖고 있어도 의미 있는 결론을 끌어낼 수 없다.

**2단계 — 데이터 수집: 필요한 것만, 정확하게**
문제가 정의되면 어떤 종류의 데이터가 필요한지, 얼마나 확보할 수 있는지가 핵심 쟁점이 된다. 데이터는 많을수록 좋다고 생각하기 쉽지만, 필요 없는 데이터까지 수집하면 분석에 노이즈가 생긴다. **양보다 질**, 즉 목적에 맞는 정확한 데이터를 수집하는 것이 중요하다.

**3단계 — 데이터 분석: 패턴과 관계를 찾는 과정**
수집된 데이터에서 의미 있는 것은 무엇인지, 데이터의 분포와 연관 관계는 어떠한지를 살피는 단계다. 많은 데이터를 수집했더라도 처음에 정의한 문제에 적합하고 의미 있는 데이터를 걸러내는 것이 첫 번째 분석 작업이다. 서로 상관관계가 있거나 의미 있는 분포를 가진 데이터를 골라내야 핵심적이고 신뢰할 수 있는 분석 결과가 나온다. 이 과정에서 데이터를 정제하는 **전처리(Preprocessing)** 작업이 필요하다.

**4단계 — AI 모델링: 패턴을 학습시키다**
분석한 데이터에서 의미 있는 관계가 나왔다면, 어떤 모델링 알고리즘을 사용할 것인가가 중요해진다. **분류**를 할 것인지, **예측**을 할 것인지, **추천**을 할 것인지에 따라 알고리즘은 달라진다. 알고리즘에 학습을 시키면 인공지능 서비스로 쓰일 수 있는 형태가 된다.

**5단계 — AI 적용: 검증하고 또 검증하다**
학습된 인공지능이 실제 문제 해결에 사용되는 단계다. 그러나 한 번에 완벽할 수 없기에 **검증과 테스트** 과정을 반복해야 한다. 필요하다면 데이터를 추가로 수집하거나 분석 단계로 돌아가 다른 연관성을 찾아보는 순환 과정이 계속된다.

#### 숫자를 읽는 사람이 세상을 읽는다

이 다섯 단계는 데이터 과학자만의 이야기가 아니다. 카페 사장이 지난달 판매 데이터를 보고 인기 메뉴를 결정하는 것도, 학교 선생님이 학생 성취 데이터를 보고 수업 방식을 바꾸는 것도 같은 흐름이다. 규모가 다를 뿐, 과정은 동일하다.

데이터 리터러시는 특별한 사람들의 전문 기술이 아니다. **‘내가 지금 보고 있는 정보가 어떻게 만들어진 것인지, 이 숫자가 전체를 대표하는 것인지, 나에게 보여 주지 않는 것은 무엇인지’**를 묻는 습관에서 시작된다.

> **“데이터를 읽는 사람이 데이터에 끌려다니지 않는다.”**

지금까지 우리는 데이터가 어떻게 만들어지고, 어떻게 쌓이며, 어떻게 우리의 일상에 영향을 미치는지를 살펴보았다. 제2부에서는 이 데이터를 **눈에 보이게 만드는 기술**, 시각화(Visualization)의 세계로 들어간다. 숫자가 그림이 되는 순간, 데이터는 비로소 모두의 언어가 된다.

### 📚 1부 정리하기

- 일상에서 우리가 만들어 내는 모든 행동은 디지털 데이터로 변환되어 축적된다.
- 추천 알고리즘은 협업 필터링·콘텐츠 기반 필터링을 결합해 작동하며, 그 목표는 **체류 시간 극대화**다.
- 필터 버블은 알고리즘이 자동으로 만들고, 에코 챔버는 사람이 스스로 선택한다.
- 비트와 바이트에서 시작된 데이터의 단위는 ZB·YB 시대로 진입했다.
- 빅데이터의 출발점은 3V(Volume·Velocity·Variety)이며, 여기에 Veracity·Value·Visualization이 더해진다.
- 데이터 분석은 **문제 정의 → 수집 → 분석 → 모델링 → 적용**의 5단계 순환 과정이다.

## 📖 제1부 수업 지도안 — 데이터 리터러시: 숫자가 말을 걸다

### 제1장 · 데이터, 지능이 되는 21세기의 원유

**학습 목표**

본 장을 마친 후 학생들은 다음을 할 수 있다.
- 일상 속 데이터 생성 과정을 구체적인 사례로 설명할 수 있다.
- 알고리즘 추천 시스템의 원리(협업 필터링·콘텐츠 기반 필터링)를 이해한다.
- 필터 버블과 에코 챔버의 차이를 구분하고, 그 영향을 비판적으로 분석한다.
- 데이터 리터러시의 개념과 필요성을 자신의 말로 설명할 수 있다.

---

**핵심 개념 정리**

| 개념 | 설명 | 수업 활용 예시 |
|------|------|----------------|
| 로그 데이터 | 사용자 행동이 시간 순서대로 기록된 데이터 | 이커머스 구매 패턴 사례 |
| 협업 필터링 | '나와 비슷한 취향의 사람'이 좋아한 것을 추천 | 유튜브·넷플릭스 |
| 콘텐츠 기반 필터링 | 내가 이미 좋아한 것과 유사한 속성을 추천 | 음악 스트리밍 |
| 필터 버블 | 알고리즘이 사용자를 '정보 거품' 안에 가두는 현상 | 2016년 미 대선 사례 |

**수업 진행 가이드**

도입 단계에서는 학생들에게 "오늘 아침에 스마트폰으로 한 행동을 3가지 적어 보세요"라고 질문하여 자연스럽게 데이터 생성 개념으로 연결한다. 이커머스 사례(쿠팡)는 학생들의 실생활과 가장 가깝기 때문에, 교사가 직접 앱을 열어 '나에게 추천된 상품'을 보여주면 학생들의 몰입도가 높아진다.

필터 버블 수업 시, '코로나 백신'을 예시로 드는 부분은 현재 사회적 민감도를 고려하여 "검색 결과는 사람마다 다르게 나타날 수 있다"는 중립적 관점에서 안내한다. 특정 정보의 옳고 그름을 판단하기보다 '왜 다르게 보이는가'에 초점을 맞춘다.

---

**수업 TIP (다문화·통합 학급 적용)**

> 필터 버블 개념은 언어 배경이 다른 학생들에게도 직관적으로 이해할 수 있는 주제다. '내가 자주 보는 것만 보여준다'는 개념을 모국어로 짧게 설명하게 하거나, 실제 유튜브·틱톡 추천 화면을 비교하는 활동은 언어 수준과 관계없이 참여할 수 있다.

### 제2장 · 현대사회의 보이지 않는 힘, 데이터

**학습 목표**

본 장을 마친 후 학생들은 다음을 할 수 있다.
- 데이터 단위(bit → Yotta Byte)의 계층 구조를 설명할 수 있다.
- 빅데이터의 3V(Volume·Velocity·Variety) 개념을 실제 사례와 연결할 수 있다.
- 정형·반정형·비정형 데이터의 차이를 구분할 수 있다.
- 시크릿 모드의 한계와 데이터 보안의 필요성을 이해한다.

---

**핵심 개념 정리**

| 개념 | 설명 | 수업 활용 예시 |
|------|------|----------------|
| 이진수(Binary) | 0과 1로 모든 정보를 표현하는 방식 | 전원 버튼 기호, 천공카드 |
| 데이터 단위 | bit → Byte → KB → … → YB | 단위 환산 퀴즈 |
| 빅데이터 3V | Volume(규모)·Velocity(속도)·Variety(다양성) | 가트너 정의 |
| 정형 데이터 | 엑셀 표처럼 규칙적 구조를 가진 데이터 | 성적표, 재고 목록 |
| 비정형 데이터 | 사진·영상·SNS 글처럼 구조가 없는 데이터 | 인스타그램 게시물 |
| 로그 데이터 | 사용자 행동이 시간순으로 기록된 데이터 | 시크릿 모드 한계 |

---

**차시별 수업 계획**

| 차시 | 학습 주제 | 주요 활동 | 자료 및 도구 | 평가 방법 |
|------|-----------|-----------|--------------|-----------|
| 1 | 0과 1, 이진수의 세계 | 클로드 섀넌 이야기 / 천공카드 실물 또는 사진 | 교재 p.10~11 | 퀴즈 |
| 2 | 데이터 단위 이해하기 | 단위 환산 카드 게임 | 단위 표 워크시트 | 게임 결과 |
| 3 | 빅데이터란 무엇인가 | 빅데이터 3V 사례 찾기 | 교재 p.14~17 | 조별 발표 |
| 4 | 데이터 보안과 시크릿 모드 | 시크릿 모드 실험 / 토의 | 교재 p.16 | 서술형 |

---

**수업 진행 가이드**

이진수 개념은 추상적으로 느껴질 수 있으므로, 교사가 직접 전원 버튼(⏻)을 가리키며 "이 기호가 사실 0과 1을 합친 것"이라는 이야기로 시작하면 학생들의 흥미를 빠르게 끌 수 있다. 클로드 섀넌의 석사 논문이 "20세기 가장 중요한 석사 논문"이라는 표현도 학생들에게 동기를 부여하는 데 효과적이다.

데이터 단위 수업은 단순 암기보다 '1분에 유튜브에 업로드되는 영상 시간(500시간 이상)이 몇 GB인가'처럼 실제 수치로 감을 잡게 하는 것이 중요하다.

---

**수업 TIP (다문화·통합 학급 적용)**

> 0과 1의 이진수 개념은 언어에 의존하지 않으므로 수준별 격차를 줄이기 좋은 단원이다. 학생들이 손가락 10개로 이진수를 표현하는 활동(0=주먹, 1=펼침)을 활용하면 몸으로 익히는 학습이 가능하다.

## 📖 제2부 수업 지도안 — 데이터 시각화: 보이지 않는 마법의 지도

### 제3장 · 기록의 역사: 인류는 무엇을 남겼는가

**학습 목표**

본 장을 마친 후 학생들은 다음을 할 수 있다.
- 인류의 기록 행위가 단순한 보존이 아닌 권력과 통치의 도구였음을 이해한다.
- 측우기의 제작 배경을 데이터 기반 의사결정의 관점에서 설명할 수 있다.
- 튀코 브라헤의 관측 데이터가 케플러 법칙으로 이어진 흐름을 설명할 수 있다.

---

| 측우기 | 1441년 문종이 주도한 세계 최초 표준 강수 측정기 | 세금·농업 데이터 연결 |

| 케플러 제1법칙 | 행성 궤도가 원이 아닌 타원임을 데이터로 증명 | 데이터가 이론을 바꾼 사례 |
| 데이터 권력 | 무엇을 기록하느냐 = 무엇을 통제하느냐 | 인구조사·사고전서 |

### 제4장 · 세상을 바꾼 시각화의 선구자들

**학습 목표**

본 장을 마친 후 학생들은 다음을 할 수 있다.
- DIKW 피라미드(데이터→정보→지식→지혜)의 단계를 실생활 사례로 설명할 수 있다.
- 존 스노우의 콜레라 지도가 데이터 시각화의 힘을 보여준 사례임을 이해한다.
- 나이팅게일의 로즈 다이어그램이 정책 변화를 이끌어낸 과정을 설명할 수 있다.

---

**핵심 개념 정리**

| 개념 | 설명 | 수업 활용 예시 |
|------|------|----------------|
| DIKW 피라미드 | 데이터(Data)→정보(Information)→지식(Knowledge)→지혜(Wisdom) | 기온 데이터 사례 |
| 데이터 시각화 | 숫자 속 패턴을 눈에 보이게 만드는 기술 | 그래프·지도·다이어그램 |
| 존 스노우 지도 | 콜레라 사망자 위치를 지도에 표시해 원인 수원을 찾아낸 사례 | 공간 시각화 |
| 미아즈마 이론 | 나쁜 공기가 병을 일으킨다는 오류 — 데이터로 반박됨 | 상관관계 vs 인과관계 |
| 나이팅게일 로즈 다이어그램 | 사망 원인별 월별 통계를 부채꼴 그래프로 표현 | 설득의 시각화 |
| 군집(Clustering) | 데이터 포인트가 특정 위치에 모이는 현상 | 이상치 분석 |

---

**차시별 수업 계획**

| 차시 | 학습 주제 | 주요 활동 | 자료 및 도구 | 평가 방법 |
|------|-----------|-----------|--------------|-----------|
| 1 | DIKW 피라미드와 시각화의 필요성 | 기온 숫자 → 그래프로 변환 실습 | 교재 p.25 / 엑셀 또는 종이 | 실습 결과물 |
| 2 | 존 스노우의 콜레라 지도 | 지도에 데이터 찍어보기 활동 | 교재 p.27~28 / 블랭크 지도 | 활동지 |
| 3 | 나이팅게일의 로즈 다이어그램 | 직접 로즈 다이어그램 그려보기 | 교재 p.30 / 색연필·원형지 | 작품 평가 |
| 4 | 시각화가 세상을 바꾼다 | 현대 데이터 저널리즘 사례 탐색 | 인터넷 검색 | 조별 발표 |

---

**수업 진행 가이드**

존 스노우 수업은 학생들이 '탐정'이 되어 사망자 데이터를 지도에 직접 찍어보는 활동으로 진행하면 매우 효과적이다. 미아즈마 이론과 실제 원인 사이의 차이를 다루면서 "보이는 것이 항상 원인은 아니다"라는 데이터 리터러시의 핵심 메시지를 자연스럽게 연결한다.

나이팅게일 수업에서는 로즈 다이어그램을 직접 그려보는 활동 전에, 같은 데이터를 일반 표로 보여주고 "어떤 형태가 더 설득력 있는가"를 먼저 토론하면 시각화의 가치를 더욱 깊이 체감할 수 있다.
